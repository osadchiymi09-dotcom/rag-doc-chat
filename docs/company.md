# О компании «ЛунаСофт»

«ЛунаСофт» — российская IT-компания, основанная в 2019 году в Санкт-Петербурге.
Основное направление — автоматизация бизнес-процессов и разработка чат-ботов
для среднего бизнеса. Штат — 42 человека, из них 18 разработчиков.

## Продукты

Главный продукт компании — платформа «Луна CRM» для управления заказами.
Она позволяет хранить клиентов, вести сделки, строить воронку продаж и
автоматически выставлять счета. Платформа написана на Python (FastAPI) и
React, развёрнута в Kubernetes.

Второй продукт — телеграм-бот «Луна-секретарь»: отвечает клиентам на
типовые вопросы, записывает встречи в календарь и передаёт сложные запросы
живому менеджеру. Обрабатывает до 5000 сообщений в день.

## Технологический стек

- Backend: Python 3.11, FastAPI, PostgreSQL, Redis, Celery
- Frontend: React, TypeScript, Vite
- Инфраструктура: Docker, Kubernetes, GitHub Actions, Grafana
- ИИ: OpenAI API, векторная база Qdrant, whisper для распознавания голоса

## Условия работы

- Гибкий график, удалёнка до 100%
- Зарплата junior-разработчика: от 80 000 до 120 000 ₽
- Средняя зарплата middle: 220 000 ₽
- Премии за релизы, оплачиваемое обучение и конференции
- Стажировки для студентов: 3 месяца с наставником, оффер после успешного
  прохождения — в 70% случаев

## FAQ для кандидатов

Вопрос: Нужен ли опыт для стажировки?
Ответ: Нет, стажировка рассчитана на студентов и выпускников без опыта.
Главное — базовые знания Python и желание учиться.

Вопрос: Сколько длится собеседование?
Ответ: Два этапа: 40 минут собеседование по коду и 20 минут с тимлидом.
Обычно занимает одну неделю от отклика до оффера.

Вопрос: Что смотреть перед собеседованием?
Ответ: Паттерны проектирования, SQL, REST API, асинхронность в Python.
