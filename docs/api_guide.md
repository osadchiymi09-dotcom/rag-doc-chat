# Руководство по API платформы «Луна»

API построен на FastAPI, документация по адресу /docs, базовый URL — https://api.lunasoft.ru/v1. Все запросы требуют заголовок `Authorization: Bearer <токен>`.

## Авторизация

Токен выдаётся в личном кабинете. Один токен привязан к одной учётной записи
и даёт права на все операции, которые разрешены пользователю. Токен можно
отозвать в любой момент — он перестанет работать в течение минуты.

## Создание заказа

```
POST /v1/orders
{
  "customer_id": "123",
  "items": [{"name": "Консультация", "price": 5000}],
  "comment": "Клиент торопится"
}
```

Ответ: 201, в теле — объект заказа с полями `id`, `status` ("created"),
`created_at`. Поле `status` меняется на "paid" после оплаты счёта.

## Ошибки

- 400 — невалидное тело запроса (список ошибок в поле `detail`)
- 401 — нет или истёк токен
- 403 — недостаточно прав
- 404 — заказ или клиент не найден
- 429 — слишком много запросов: лимит 100 запросов в минуту на токен

При 429 в заголовке `Retry-After` указано, через сколько секунд можно
повторить запрос.

## Пагинация

Списочные эндпоинты (`/v1/orders`, `/v1/customers`) возвращают страницы по
50 записей. Параметр `page` начинает с 0, в ответе есть поле `next` с URL
следующей страницы или null, если страниц больше нет.

## Вебхуки

События (order.paid, order.created) приходят на URL, указанный в настройках.
Заголовок `X-Luna-Signature` — HMAC-SHA256 от тела запроса, секрет из
настроек. Чтобы подтвердить, что вебхук получен, верни HTTP 200.
